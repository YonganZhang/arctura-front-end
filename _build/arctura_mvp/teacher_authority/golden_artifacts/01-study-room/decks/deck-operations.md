## 空间使用分区
- **书墙区**：500 册容量 · 底柜隐藏收纳（建议放杂物 / 打印机 / 季节衣物）
- **工作区**：面西 · 下午光好 · 双屏布置 · 桌下理线
- **阅读角**：东南角 · 单人沙发 + 落地灯 · 地毯围合
- **走道**：中间 1.2 m，不放物件（动线关键）

## 书墙日常使用
- **承重**：每层 50 kg，满书放心
- **顺序**：建议按主题或颜色分层（视觉更统一）
- **防尘**：上层和顶格建议 2 个月擦一次（鸡毛掸 + 干布）
- **防潮**：南方梅雨季放一包防潮剂在每层角
- **底柜**：push 磁吸门，轻按开合，不要硬拉（磁吸 3-5 年后需换）

## 安全与防范

| 风险 | 措施 |
|---|---|
| **书墙倾倒** | 顶部 L 角铁已固定天花龙骨，不要自行拆 |
| **插座过载** | 工作桌插座总功率 ≤ 1500W，不要串接热水壶等大功率设备 |
| **地毯打滑** | 底部已加防滑垫，每年检查一次 |
| **落地灯磕碰** | 底座 2 kg 配重，正常使用不会倒 |
| **火灾** | 书房无明火，但纸书密集 → 楼层烟感必须通电 |

## 常见问题处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 书墙轻微晃动 | 顶部螺栓松动 | 拧紧 L 角铁膨胀螺栓 |
| 搁板轻微下沉 | 书过满超载 | 中段立柱加托 / 减书 |
| 磁吸门关不紧 | 磁吸老化 / 错位 | 更换磁吸扣（¥20/个） |
| 落地灯闪烁 | 灯泡或调光器 | 换灯泡 → 换调光模块 |
| 墙漆局部污渍 | 渗色 | 细砂纸轻磨 + 原色补刷 |
| 地板缝开裂 | 干燥季节 | 加湿器 + 季节性微收缩正常 |

# 使用仪表盘建议

> 建议每月快速自检 5 分钟

- ✓ 书架稳固性（晃一下）
- ✓ 灯具全亮
- ✓ 插座全通
- ✓ 无明显污渍 / 裂痕
- ✓ 防潮剂颜色（蓝=干 / 粉=湿，需换）
